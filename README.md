# Росмолодёжь — Цифровая стратегия 2026

Интерактивный веб-отчёт по цифровой стратегии Федерального агентства по делам молодёжи на 2026 год. Документ подготовлен 27 апреля 2026 года.

## Содержание

- Резюме для руководства
- Часть I — Стратегический фокус: мессенджер MAX (разделы 1–8)
- Часть II — Поддерживающие платформы (ВКонтакте, сайт, Дзен)
- Часть III — Конкурентная среда
- Часть IV — Медиаплан 2026 (январь–декабрь)
- Приложение — Фирменный стиль «Код молодёжи»

## Запуск локально

Проект является статическим сайтом. Для корректной загрузки шрифтов и ресурсов необходим локальный HTTP-сервер (открытие `index.html` напрямую через `file://` может не загружать шрифты в некоторых браузерах).

### Вариант 1 — Python (рекомендуется)

```bash
# Python 3
python -m http.server 8000

# Затем откройте в браузере:
# http://localhost:8000
```

### Вариант 2 — Node.js

```bash
npx serve .
```

### Вариант 3 — VS Code

Установите расширение **Live Server** и нажмите «Go Live» в правом нижнем углу.

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите все файлы проекта в корень репозитория.
3. В настройках репозитория перейдите в **Settings → Pages**.
4. В разделе **Branch** выберите ветку `main` и папку `/ (root)`.
5. Нажмите **Save**.
6. Сайт будет доступен по адресу: `https://<username>.github.io/<repo-name>/`

> Файл `.nojekyll` включён в проект, чтобы GitHub Pages корректно обрабатывал папку `fonts/` без Jekyll-обработки.
